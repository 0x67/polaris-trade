# plugin

Package `polaris-plugin` is the versioned C ABI for venue adapter plugins. A
plugin crate turns a `VenueAdapter` into the vtable it exports as
`polaris_adapter_entry`, and a host checks that vtable and runs its adapters
as `DynAdapter`s, so a closed adapter can be delivered as a shared library and
loaded by an open binary.

The crate depends on `polaris-events` and `polaris-pipeline` and nothing of the
datafeed runtime. Architecture notes are in `lat.md/plugin.md` at the
repository root.

## Exporting an adapter

A plugin is a `cdylib` crate that depends on `polaris-plugin` by git tag and
invokes `export_adapter!` once:

```rust
use polaris_plugin::export::Venue;

polaris_plugin::export_adapter!(
    adapter: MyAdapter,
    venue: Venue {
        name: c"myvenue",
        tag: c"myvenue",
        version: c"v1",
        feed_id: 7,
        soupbin_live: false,
        session: MY_SESSION,
    },
    config: my_config,
);

// `create` hands the plugin a JSON object holding at least `venue_id` and
// `session_midnight_ns`; `None` refuses it with POLARIS_PLUGIN_ERR_CONFIG.
fn my_config(json: &str) -> Option<MyConfig> {
    serde_json::from_str(json).ok()
}
```

The venue's streams are `MyAdapter::streams()` in its order, so the first is
the stream whose trades feed the session's bars. `session` must equal what the
adapter's `session()` returns, or the host refuses its adapters.

Build the plugin with the workspace `ffi` profile, or any profile with
`panic = "unwind"`:

```bash
cargo build --profile ffi -p my-plugin
```

Every entry point catches a panic, returns `POLARIS_PLUGIN_ERR_PANIC` and
poisons the handle it happened on. A plugin built with `panic = "abort"`,
the workspace `release` setting, aborts the host process on a panic instead.

## Hosting a plugin

```rust
use md_pipeline::DynAdapter;
use polaris_plugin::Plugin;

// SAFETY: the vtable comes from a loaded plugin library that stays loaded.
let plugin = unsafe { Plugin::new(vtable) }?;
let venue = plugin.venue();
let mut adapter = plugin.create(c"{\"venue_id\": 2, \"session_midnight_ns\": 0}")?;
adapter.feed(venue.streams[0], payload, ts_recv, venue_seq);
adapter.drain_into(&mut events);
if let Some(fault) = adapter.fault() { /* the adapter stopped */ }
```

`Plugin::new` reads `abi_version` before any other field and refuses a vtable
of another `POLARIS_PLUGIN_ABI_VERSION`, naming both versions. Every record a
plugin hands out is checked (rtype, length, enum fields) before it becomes a
`MarketEvent`; a bad one, a panic, or any failed call sets the adapter's
`AdapterFault`, and the datafeed session runner ends the session on it.

## C header

The C view of the ABI is part of `crates/datafeed-ffi/include/polaris_abi.h`,
generated by cbindgen from this crate's `src/abi.rs` together with the
embedding API. A plugin written in C implements `polaris_adapter_vtable` and
exports `const polaris_adapter_vtable *polaris_adapter_entry(void)`.

## Tests and bench

```bash
cargo nextest run -p polaris-plugin
cargo bench -p polaris-plugin --bench plugin_path
```

The library tests run the export and the host wrapper over a test plugin of
the test binary, and CI also runs them under Miri.
`tests/nasdaq_plugin.rs` runs NASDAQ through both against the native adapter
over the committed fixtures. The bench prints ns per record for the plugin path
and the native boxed adapter.
